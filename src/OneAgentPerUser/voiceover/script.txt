# One AI lifecycle agent per user: voiceover script, shared by every story
#
# Each video is voiced as ONE take, so tone and pace stay consistent.
# "@ Label" lines just mark sections; each section becomes its own paragraph,
# and the paragraph break gives a natural pause between sections. The empty
# section (Decision) comes from the story: stories/<story>.txt.
#
# The model is eleven_v3: [excited] and other audio tags set the delivery, and
# pauses inside a line come from "…" and dashes (v3 has no break tags).
#
# The video follows the voice: the pins in ../timeline.ts tie visual moments
# to phrases in this script (e.g. the paths swell into the next scene after
# "just for them") and hold the animation as long as needed. If you reword a
# phrase a pin names, update the pin too.
#
# Regenerate after editing: npm run voiceover -- --story all --voice all
